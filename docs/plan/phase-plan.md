## 阶段 1：基础工程与后端 MVP

### 阶段目标

建立可运行的 FastAPI 后端基础工程，完成用户、题库、练习、答题记录和错题本的基础能力。

### 主要任务

- 初始化 Python 后端工程。
- 配置 FastAPI、Pydantic、SQLAlchemy、Alembic。
- 接入 PostgreSQL 和 Redis。
- 建立统一配置、日志、错误处理和接口响应规范。
- 实现用户登录基础结构。
- 实现题库基础模型。
- 实现练习会话和答题记录。
- 实现错题本。
- 补充基础测试。

### 完成标准

- 后端可本地启动。
- 数据库迁移可执行。
- 核心业务接口可通过测试或手工验证。
- 阶段结束时完成一次中文规范提交。

## 阶段 2：Agent MVP

### 阶段目标

实现最小可用 Agent 能力，让用户可以围绕题目获得 AI 讲解，并保留对话、模型调用和工具调用记录。

### 主要任务

- 初始化 Agent 模块入口。
- 接入至少一个大模型供应商。
- 建立 Prompt 模板管理方式。
- 实现单题讲解工作流。
- 实现查询题目信息的 Agent 工具。
- 记录 Agent 会话、消息、工具调用和用量。
- 增加基础错误处理和降级提示。

### 完成标准

- App 或接口可以请求单题讲解。
- Agent 能通过工具读取题目信息。
- 调用记录可追踪。
- 阶段结束时完成一次中文规范提交。
